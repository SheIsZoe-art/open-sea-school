# The Sea University

Playful ocean-themed learning with Captain Claw. 810 courses, nine subjects, approximate ages 6–15.

## Play

https://sheiszoe-art.github.io/open-sea-school/

## Offline

Download Open-Sea-School-English.zip, extract it and open OPEN-SEA-SCHOOL.html in a modern browser. Export the JSON journal regularly. Online and local browser storage are separate.

See USER-MANUAL.html for detailed instructions and SOURCES-AND-COVERAGE.html for educational limits. This is not an accredited school.
